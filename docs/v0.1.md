# v0.1 - MVP

# Product Scout AI V0.1

## 1. Objective

Validate whether an Agent can perform useful product discovery research from a natural language product goal.

---

## 2. Example Input

```json
{
  "goal": "寻找适合美国小企业的 AI SaaS",
  "constraints": {
    "market": "US",
    "price": "$20-$100/month",
    "competition": "low"
  }
}
```

## 3. Expected Output

The system should produce:

### Market Summary
* target market
* target users
* market context
* important trends

### Pain Points
For each pain point:
* description
* affected users
* frequency
* evidence
* confidence

### Competitors
For each competitor:
* product
* target users
* pricing
* core features
* positioning
* customer complaints
* weaknesses

### Market Signals
* trends
* new products
* funding
* search interest
* community discussions
* regulatory or technology changes

### Opportunities
Each opportunity contains:
* title
* target customer
* problem
* evidence
* solution
* why now
* monetization
* MVP
* score
* confidence

### Validation Plan

A 7-day plan:

Day 1:
Problem interviews

Day 2:
Landing page

Day 3:
User acquisition

Day 4:
Prototype

Day 5:
Early users

Day 6:
Measure

Day 7:
Decision

## 5. Acceptance Criteria
AC-01

User can create a project.

AC-02

User can start research.

AC-03

Agent executes web research.

AC-04

Agent produces sources.

AC-05

Agent produces evidence.

AC-06

Agent produces competitor analysis.

AC-07

Agent produces pain point analysis.

AC-08

Agent produces opportunities.

AC-09

Opportunity scores are reproducible.

AC-10

Every major opportunity can be traced to evidence.

AC-11

Frontend displays live research progress.

AC-12

Research can be cancelled.

AC-13

Research timeout is handled.

AC-14

Agent cannot perform forbidden external side effects.

AC-15

Client can observe ResearchRun Product Events over SSE and replay events after
the Last-Event-ID cursor.

## 6. V0.1 Non-Goals

Do not build:

* billing
* team collaboration
* mobile app
* browser extension
* social media publishing
* CRM
* email automation
* multi-agent architecture
* vector search
* recommendation engine
