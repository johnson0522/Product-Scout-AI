## Scope and environment

The initial product is a local, single-owner evaluation application. The server
binds to loopback; the owner comes from server configuration, never request
input. Remote or multi-user deployment requires an explicit authentication
decision and is outside this local acceptance. Existing DSH isolation and
database safety gates remain in force. No queues, restart recovery, framework
changes, or historical migration rewrites are planned.

Acceptance will record each AC from docs/v0.1.md against executed checks.
Missing PostgreSQL, browser binaries, model credentials, or search transports
must be reported as BLOCKED; mock results are not live-provider acceptance.
