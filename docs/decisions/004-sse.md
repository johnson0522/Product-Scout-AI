# ADR-004: Server-Sent Events

## Status

Accepted

## Decision

Use SSE for research progress streaming.

## Reasons

V0.1 mainly requires:

Server → Browser

streaming.

Examples:

- research started
- step started
- tool started
- evidence created
- opportunity created
- research completed

SSE is simpler than WebSocket for this requirement.

## Future

WebSocket can be introduced if bidirectional realtime communication becomes a product requirement.
