
# ADR-001: Use Next.js

## Status

Accepted

## Decision

Use:

React + Next.js + TypeScript

for the Product Layer.

## Reasons

- strong React ecosystem
- suitable for SaaS products
- server/client rendering flexibility
- API Route Handlers
- good TypeScript support
- suitable for AI product interfaces

## Alternatives

Vue/Nuxt was considered.

The decision is based on product ecosystem and AI application development requirements rather than existing developer experience.

## Consequences

The frontend team must use React patterns and avoid mixing Vue architecture concepts into the codebase.
